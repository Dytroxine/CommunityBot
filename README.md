# Community Bot

Telegram бот для управления комьюнити в чатах. Фильтрует новых участников капчей, считает активность, выдаёт уровни, статусы и промокоды за сообщения, раз в неделю объявляет самых активных пользователей и даёт администраторам панель управления прямо в Telegram.

## Возможности

- Антибот проверка: новый участник подаёт заявку на вступление, получает кнопку подтверждения и 5 минут на её нажатие. Не нажал, бот удаляет его из чата
- Подсчёт сообщений с защитой от накрутки: короткие сообщения, ссылки, подряд идущие сообщения одного человека и сообщения чаще раза в 10 секунд не учитываются
- Уровни и статусы: уровень растёт каждые 30 сообщений, статус каждые 5 уровней, максимум 750 сообщений на пользователя
- Награды: за статусы Beginner, Enthusiast, User, Fan и Master пользователь забирает промокод через личные сообщения с ботом
- Недельный лидерборд: по понедельникам в 11:00 бот публикует топ 3 самых активных
- Вопросы для обсуждения из Google Sheets с отметкой уже использованных строк красным цветом
- Локализации текстов уведомлений для разных чатов
- Админ панель в личных сообщениях с ботом

## Как это работает

1. Пользователь подаёт заявку на вступление. Бот пишет ему в личку, временно запрещает писать в чате и ждёт нажатия кнопки.
2. После подтверждения ограничения снимаются. Если за 5 минут кнопка не нажата, пользователь удаляется из чата.
3. Каждое подходящее сообщение в чате увеличивает счётчик пользователя и счётчик в лидерборде чата.
4. При достижении нового уровня или статуса бот пишет поздравление в чат.
5. В личке с ботом пользователь смотрит свой уровень и забирает доступные промокоды.
6. Администраторы и чат админы в подсчёте не участвуют.

## Установка

Нужен Python 3.9 или новее.

```bash
git clone https://github.com/Dytroxine/CommunityBot.git
cd CommunityBot
pip install -r requirements.txt
```


## Настройка

При первом запуске бот сам создаёт файл `config.env`. Заполните его:

```
bot_token=ТОКЕН_ОТ_BOTFATHER
bot_password=ПАРОЛЬ_ДЛЯ_ВХОДА_В_АДМИНКУ
```

В `vars.py` укажите идентификаторы чатов. Первым идёт русскоязычный чат, вторым англоязычный:

```python
self.chats = [-1001234567890, -1009876543210]
```

Для вопросов из Google Sheets:

1. Создайте сервисный аккаунт в Google Cloud и положите его ключ в `credentials.json`.
2. Дайте сервисному аккаунту доступ к таблице.
3. Впишите идентификатор таблицы в `spreadsheet_id` в `admin_handlers.py`.

В таблице в колонке A лежат вопросы для английского чата, в колонке B для русского.

В чатах бот должен быть администратором с правами на ограничение и удаление участников и приглашения. Для капчи в чате включите вступление по заявкам.

## Использование

Для пользователей:

1. Отправить боту `/start`.
2. Кнопка Current level показывает уровень и статус.
3. Кнопка My rewards показывает полученные и доступные награды и позволяет забрать промокоды.

Для администратора:

1. Отправить боту `/admin пароль`.
2. Через меню загрузить промокоды файлом xlsx. В первой колонке код, во второй уровень награды.
3. Выгрузить список промокодов или лидерборд в xlsx.
4. Добавить или удалить чат админов, чаты и локализации.
5. Запустить лидерборд в выбранном чате вручную.

## База данных

SQLite, таблицы создаются автоматически:

- users: пользователи и общее число сообщений
- rewards: выданные промокоды по уровням
- promocodes: свободные промокоды
- leaderboard: сообщения по чатам за неделю
- chats и localisations: чаты и тексты уведомлений
- admins и chat_admins: администраторы бота и чатов

## Примечания

- Файлы `config.env`, `credentials.json` и `database.db` содержат секреты и данные пользователей, добавьте их в `.gitignore`
- Вечерняя рассылка вопросов настроена на 3000 год, то есть фактически отключена. Чтобы включить, измените CronTrigger в `setup_evening_message_scheduler`
- Идентификаторы чатов для лидерборда частично заданы прямо в коде
